## 2. 玻璃材质：改了哪些 token

关键判断：**玻璃在「纯白 + 巨大色块」的背景上之所以认不出来，不是 alpha 一个变量的问题**，而是「底太实 + 边缘无高光 + 层与层之间没有明度差」。所以这轮同时动了四件事：

1. 面板底更透（light .72 → .54）；
2. 卡片反而更实（.62 → .68），**底透、层实**才有层次；
3. 加了两样「玻璃的边缘语言」：顶部径向 sheen + 1px 亮边（`--awu-glass-edge`）；
4. 内阴影改成方向性的（上亮、下暗），模拟光源在左上。

| token | 旧值 | 新值 | 为什么 |
|---|---|---|---|
| `--awu-glass-1`（深色） | `rgba(28,28,30,.72)` | `rgba(20,20,24,.66)` | 更透，同时压暗保对比 |
| `--awu-glass-1`（浅色） | `rgba(255,255,255,.72)` | `rgba(255,255,255,.54)` | 主人要的「透感」 |
| `--awu-glass-2`（浅色） | `.62` | `.68` | 卡片比底更白 → 浮起来 |
| `--awu-glass-2`（深色） | `rgba(58,58,60,.42)` | `rgba(72,72,82,.44)` | 同上 |
| `--awu-glass-2-hi` | 新增 | 浅 `.86` / 深 `.52` | hover 提亮档（不叠加灰罩） |
| `--awu-sheen` | 新增 | 浅 `.46` / 深 `.13` | 顶部 specular 高光强度 |
| `--awu-glass-edge` | 新增 | 浅 `.78` / 深 `.20` | 玻璃 1px 亮边 |
| `--awu-blur-panel` | `blur(16px) saturate(160~170%)` | 浅 `blur(18px) saturate(185%) brightness(1.03)`；深 `blur(20px) saturate(150%)` | 1120×900 大面积控制在 12–20px 区间 |
| `--awu-scrim-bg` | 浅 `.20` / 深 `.38` | 浅 `.16` / 深 `.36` | 压暗层别把背景色吃掉 |
| `--awu-shadow`（浅色） | `0 24px 60px .16, 0 2px 8px .08` | `0 34px 84px .24, 0 6px 20px .10` | 玻璃面板要「浮」起来 |
| `--awu-shadow-card` / `-hi` | 新增 | 见下 | 卡面静息/悬停两档阴影 |
| `--awu-surface-opaque` | 新增 | 浅 `#f6f6f8` / 深 `#1e1e21` | **降级用实心底** |

面板本体（`.awu-panel`）现在是这样叠出来的：

```
background-color: var(--awu-glass-1)                        ← 透光底色
background-image: 径向 sheen（顶部）+ 竖向亮带（前 12%）      ← 高光
border: 1px solid var(--awu-glass-edge)                     ← 亮边
box-shadow: 面板投影 + 100vmax 压暗 + inset 顶部亮线 + inset 1px 内亮边
backdrop-filter: blur + saturate(+brightness)
```

左栏（`.awu-rail`）额外压了一层 3% 的灰（`--awu-surface-strip`）：两栏同材质时中间那道 1px 分隔线太弱，列表会「浮」在面板上。

### 降级（硬约束）

`@media (prefers-reduced-transparency: reduce)` 过去写的是 `background: var(--awu-surface)` —— 而那本身就是半透明玻璃，等于「关掉透明仍然透明」。现在改成：

```
background-image: none;
background-color: var(--awu-surface-opaque);
backdrop-filter: none;
```

`prefers-reduced-motion` 原有关闭清单保持有效，新增的 `awu-card:active` 位移也在 `transition-duration: .01ms` 覆盖范围内；另外卡片 hover 的 `transform` 已有 `animation: none` + `transform: none` 兜底。

### 3.4 衬线到底留给谁（结论）——附证据

**结论：衬线只留 `.awu-line`（日记正文）与 `.awu-avatar` / `.awu-mark` 的字形块；角色名改成黑体 600 + 角色金。**

理由（`06-tmp/z3.png` 那张 3 倍放大图）：`--awu-serif` 在 Windows 上以前根本没生效（Georgia 无中文字形），补上 `SimSun` 之后「虞照」变成了 18px 宋体——**笔画细、横竖对比大，放在实心黑体的 UI 里明显发虚**，正是主人说的「辨认困难」。改成黑体 600 后（`06-tmp/qa-card-hover.png`）名字反而更实、更有分量；辨识度由「角色金 + 头像色块」承担，没有丢。

其余一律黑体（在文件末尾统一裁决，靠顺序赢，避免逐条漏改）：

```
.awu-textarea, .awu-editArea, .awu-editListText, .awu-editorName,
.awu-previewName, .awu-focusInput, .awu-focusRead { font-family: var(--awu-sans); }
```

> 日记正文保留衬线是有意的：它是「读一段日记」的阅读面，不是控件。若主人觉得日记正文也发虚，下一轮改 `.awu-line` 一处即可。

## 7. 需要 Lead 处理 / 下一批

### 7.1 需要 Review 的越界小改（1 处，2 行）

`tools/preview/index.html` 加了深色态开关（仅开发沙盒，不进 `lib`、不影响插件）：
地址带 `?dark=1`（或 `#dark`）时给 `<html>` 打 `data-ds-dark-theme`。**不加这个就没法在沙盒里验收深色态**。若不接受请回退这两行，我改用别的办法。

### 7.2 需要 JSX 配合的清单（我做不了，按优先级）

1. **空态能否区分场景**：给 `.awu-empty` 加 `data-kind="pick|empty|diary"`。现在 CSS 无法区分「右栏未选卡」与「角色簿为空」，两者只能共用一套视觉；有了 data-kind，我可以给「未选卡」加一个指向左栏的箭头指示。
2. **右栏空态第二行文案**：现在只有「从左栏选一张卡」一句，居中后偏单薄。建议 JSX 加一行副文案（如「或在左上角从作品蒸馏一张卡」），并给 `text.ts` 加 key。
3. **状态带右端空间**：「当前没有启用角色」那一行右侧整片空着。若能加一个次级文字按钮（如「去挑一张卡 →」，触发 `openDialog('new')` 或滚动到列表），这条带子会从「提示条」变成「行动条」。
4. **统计条指标**：三格是 角色 / 记忆 / 对话。若想更有信息量（如「最近活跃」），需要 JSX + overview 接口字段。
5. **详情页 hero**：三个按钮（编辑/启用/删除）在窄屏会挤，建议确认是否允许降级成图标 + 溢出菜单（CSS 已 `flex-wrap` 兜底，不阻塞）。

### 7.3 下一批我要做的（不需要 JSX 也能做）

- **深色态二次调**：`--awu-glass-1` 深色 .66 → .72、`saturate` 150% → 135%，加一点顶部 sheen（现在暗色偏「烟灰」，亮壁纸下略浑）。
