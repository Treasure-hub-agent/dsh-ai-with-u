## 1. 新文件 `client/a11y.ts` 的 API（你只需按顺序调用）

| hook | 签名 | 职责 |
|---|---|---|
| `useRestoreFocus` | `(active = true) => void` | 激活瞬间记下 `document.activeElement`，取消激活 / 卸载时还回去；元素已 `isConnected === false` 或原本是 `body` 则跳过 |
| `useInitialFocus` | `<T extends HTMLElement>(ref: RefObject<T \| null>, active: boolean, selector?: string) => void` | 显式 `selector` → `[autofocus]` → 第一个可见可聚焦元素 → 容器自身（补 `tabindex="-1"`）；容器内已经有焦点时不抢 |
| `useFocusTrap` | `<T extends HTMLElement>(ref: RefObject<T \| null>, active: boolean) => void` | Tab / Shift+Tab 在容器内闭环；只处理 `Tab`，Esc 留给调用方；模块级栈保证嵌套时只有最上层接管 |

**调用顺序不能换**（同一组里固定写成三行）：

```ts
useRestoreFocus()             // ① 先记回来处（必须在焦点被挪走之前）
useInitialFocus(boxRef, true) // ② 再把焦点送进容器
useFocusTrap(boxRef, true)    // ③ 最后拦住 Tab
```

三条实现上的取舍（与设计稿 §7.1 草稿的差异，行为是它的超集）：

1. **拆成三个 hook**：`card-editor` 的确认层需要「陷阱常开、还焦只一次」，一个合体 hook 表达不了。
2. **可见性用 `getClientRects()` 而不是 `offsetParent`**：`position: fixed` 的容器在某些内核里 `offsetParent` 为 `null`，会被误判成隐藏。
3. **所有 DOM 调用都 try/catch + `console.warn('[ai-with-u] …失败，已跳过', error)`**：旧内核不支持
   `focus({preventScroll: true})` 时自动回退无参 `focus()`；任何异常都只警告，不打断渲染。

## 2. `Overlay`（`client/index.tsx:131-163`）

### 2.1 先加导入（锚点：`import type { CSSProperties, JSX, KeyboardEvent as ReactKeyboardEvent } from 'react'`，:13）

```tsx

```

放在 :13 之后、:15 的 `import {`（`./api`）之前。`useRef`（:11）与 `ReactKeyboardEvent`（:13）都已存在，不需要再加。

### 2.2 整段替换（锚点：`function Overlay(props: {`，:131）

```tsx
/** 弹层通用行为：Esc 关闭 + 点击遮罩关闭 + 焦点陷阱（Tab 不出去、关闭后焦点回原位）。 */
function Overlay(props: {
  label: string
  onClose: () => void
  children: JSX.Element | JSX.Element[]
}): JSX.Element {
  const { label, onClose, children } = props
  const boxRef = useRef<HTMLDivElement | null>(null)
  useScrollLock(true)

  // 焦点顺序不能换：先记回来处 → 再把焦点送进容器 → 最后拦 Tab。
  useRestoreFocus()
  useInitialFocus(boxRef, true)
  useFocusTrap(boxRef, true)

  useEffect(() => {
    const onKey = (event: KeyboardEvent): void => {
      if (event.key === 'Escape') {
        event.stopPropagation()
        onClose()
      }
    }
    document.addEventListener('keydown', onKey, true)
    return () => document.removeEventListener('keydown', onKey, true)
  }, [onClose])

  return createPortal(
    <div
      className="awu-scrim"
      role="presentation"
      onMouseDown={event => {
        if (event.target === event.currentTarget) onClose()
      }}
    >
      <div ref={boxRef} className="awu-dialog" role="dialog" aria-modal="true" aria-label={label}>
        {children}
      </div>
    </div>,
    document.body,
  )
}
```

改动只有三处：`boxRef` 声明、三个 hook、把 `ref={boxRef}` 挂到 `.awu-dialog`。`useScrollLock`、Esc、点遮罩逻辑原样保留。

### 2.3 为什么这样排不会抢弹层自己的焦点

`Overlay` 是**弹层组件的子组件**（`NewCharacterDialog` → `Overlay`），React 的 effect 先跑子层：
`useInitialFocus` 先按「第一个可聚焦元素」落焦，紧接着弹层自己的 `focus()` effect 落在同一个输入框上。
两者目标一致，不会出现"先闪到按钮再跳回输入框"的可见跳动。

## 4. 分段器（`client/index.tsx:1377-1418`）

### 4.1 在 `CharacterPanel` 里加常量与键盘处理

插入点：`const panelStyle: CSSProperties = {...}` 结束（:1217）之后、`// -------------------------------------------------------- 渲染`（:1219）之前。

```tsx
  // 分段器：roving tabindex + 方向键 / Home / End（A4/A5）。
  // 面板里只有**一个** tabpanel（.awu-body），所以 aria-controls 永远指向存在的元素。
  const TAB_IDS: Array<{ id: Tab; node: string }> = [
    { id: 'roster', node: 'awu-tab-roster' },
    { id: 'diary', node: 'awu-tab-diary' },
    { id: 'stats', node: 'awu-tab-stats' },
    { id: 'guide', node: 'awu-tab-guide' },
  ]
  const tabIndex = Math.max(0, TAB_IDS.findIndex(item => item.id === tab))
  const tabNode = TAB_IDS[tabIndex].node

  const onTabKey = (event: ReactKeyboardEvent<HTMLDivElement>): void => {
    // 带修饰键的组合（⌘/Ctrl + ←）留给宿主或输入法，不抢
    if (event.altKey || event.ctrlKey || event.metaKey) return
    const delta = event.key === 'ArrowRight' ? 1 : event.key === 'ArrowLeft' ? -1 : 0
    const jump = event.key === 'Home' ? 0 : event.key === 'End' ? TAB_IDS.length - 1 : -1
    if (delta === 0 && jump < 0) return
    event.preventDefault()
    const next = jump >= 0 ? jump : (tabIndex + delta + TAB_IDS.length) % TAB_IDS.length
    setTab(TAB_IDS[next].id)
    document.getElementById(TAB_IDS[next].node)?.focus()
  }
```

> `TAB_IDS` 的 4 项与当前 `Tab` 类型（`index.tsx:84`：`'roster' | 'diary' | 'stats' | 'guide'`）一致。
> 若你先把本清单落地、后合指南，把 `guide` 那行去掉即可（`panel.tab.guide` 键已在工作区 `text.ts` 里）。

### 4.2 整段替换（锚点：`<div className="awu-tabs" role="tablist"`，:1377；到 `</div>`，:1418）

```tsx
          {/* 分段器 */}
          <div className="awu-tabs" role="tablist" aria-label={t('panel.title')} onKeyDown={onTabKey}>
            {TAB_IDS.map(item => (
              <button
                key={item.id}
                id={item.node}
                type="button"
                role="tab"
                className="awu-tab"
                data-on={tab === item.id ? 'true' : 'false'}
                aria-selected={tab === item.id}
                aria-controls="awu-tabpanel"
                tabIndex={tab === item.id ? 0 : -1}
                onClick={() => setTab(item.id)}
              >
                {t(`panel.tab.${item.id}`)}
              </button>
            ))}
          </div>
```

要点：

- `data-on` 留给 CSS（ui-designer 的样式仍按它选中态），`aria-selected` 留给读屏，两者并存；
- `tabIndex` 游走：只有当前 tab 是 Tab 停靠点，方向键切换时同步 `setTab` + 焦点（自动激活）；
- `t(\`panel.tab.${item.id}\`)` 是模板键，`text.ts` 里四个键都已存在，**不需要新增字典**；
- 视觉层若被 ui-designer 改名（`.awu-tabs` / `.awu-tab`），只影响外观，不影响这段行为代码。

## 5. 主体 `tabpanel`（`client/index.tsx:1421`）

把单行：

```tsx
          <div className="awu-body">
```

替换为：

```tsx
          <div
            className="awu-body"
            id="awu-tabpanel"
            role="tabpanel"
            aria-labelledby={tabNode}
            tabIndex={0}
            aria-busy={busy}
          >
```

要点：

- `tabNode` 来自 §4.1，4 个 tab 都有 id，`aria-labelledby` 永远有效；
- `tabIndex={0}` 让键盘用户可以 Tab 进内容区用 `↑/↓` 滚动（面板本体不是模态，不能靠 trap 兜）；
- `aria-busy={busy}` 让读屏知道"正在处理中"（React 会输出 `"true"` / `"false"`）；
- 面板本体（`.awu-panel`，`role="dialog" aria-modal="false"`）**保持不加焦点陷阱**：点外面就关、
  Tab 必须能走出去，加 trap 是错语义。设计稿 §7.1 末尾也这么写。
